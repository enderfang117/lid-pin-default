How it works

A small listener with a reversible policy change.

No driver, account, or cloud service is required.

01

Listen

Uses the Windows lid-switch power notification instead of guessing from display state.

02

Prefer PIN

When closed, PIN becomes the default and face/fingerprint credential providers are temporarily excluded.

03

Restore

Opening the lid restores the exact policy values saved during installation.

Install

One command. Fully removable.

Download the script, open Windows PowerShell as Administrator, and run the command.

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\LidPinDefault.ps1" -Install
!

Test it on your device

Windows 10/11, an existing Windows Hello PIN, and administrator access are required. OEM utilities and organization-managed policies may change the result. While the lid is closed, biometric credential providers are also excluded from application authentication prompts. This is not a security boundary or an official Microsoft tool.
